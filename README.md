Harly is an **open-source, self-hosted ATS** — an alternative to Ashby, Greenhouse, and Workable — built so startups and small teams don't have to pay $499+/month just to hire. Full recruiting pipeline, career page builder, candidate portal, native e-signatures, and a one-command CLI installer. MIT licensed.
